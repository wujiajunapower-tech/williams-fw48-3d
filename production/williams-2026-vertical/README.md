## 使用说明

先录音，再按P01至P09建立声音骨架；配合G01至G04图卡，最后从A编号指南补充所需的外部画面。图卡是静态素材，动画需要在剪辑软件中另做。

2025数据为完整赛季，2026数据为截至新加坡站后，不能作为等长赛季直接计算同比跌幅。车队公开解释、正式赛果与节目评论在资料中分别标明。

外部照片、视频只提供查找入口，未打包下载或取得公开剪辑发布许可。图卡为原创解释图，不是FW48官方CAD、CFD或遥测。
